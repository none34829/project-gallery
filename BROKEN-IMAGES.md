# Hero images

Each project's hero image comes from Airtable's `graphic_link`, which is a **hotlink**
to a third-party site. Those links rot - **34 of 188** had stopped loading, and because
they are painted as CSS backgrounds they failed *silently* to a blank white box.

## What the site does now

1. **20** projects show a figure lifted from the student's own research paper,
   self-hosted in `src/assets/images/project_graphics/` so it cannot rot. Generated by
   `python figures-from-papers.py`, which scores candidate figures and skips code
   screenshots, raw tables and bare equations.
2. The remaining **14** fall back to a gradient tinted by the project's subject, so
   nothing renders as an empty box.
